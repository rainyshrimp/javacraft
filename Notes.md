## Commandes Linux
```bash
# Effacer le terminal
clear

# Administrateur (fait rien tout seul)
sudo

# Rafraîchir les applis installés
sudo apt update

# Mettre à jour les applis
sudo apt upgrade
sudo apt upgrade -y # Oui automatique, raccourci

# Rechercher une appli
sudo apt search firefox

# Installer une appli
sudo apt install firefox
```
